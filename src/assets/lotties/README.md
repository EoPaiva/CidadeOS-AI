# Biblioteca futura de animações institucionais

Coloque aqui apenas animações `.json` ou `.lottie` com licença adequada e estética compatível com governo digital, cidade inteligente, transparência, protocolo, saneamento, defesa civil e saúde pública.

Arquivos planejados:
- cidade-inteligente.json
- protocolo-gerado.json
- ocorrencia-analise.json
- defesa-civil-alerta.json
- saude-publica.json
- agua-saneamento.json
- transparencia-dados.json
- atendimento-cidadao.json
- loading-cidadeos.json
- empty-state-institucional.json

Nesta fase não foram incluídos assets externos para evitar risco de licença/peso. A interface usa animações SVG/CSS leves com `prefers-reduced-motion`.
